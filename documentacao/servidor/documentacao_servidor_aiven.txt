\chapter*{Resumo}

\chapter{Servidor Aiven}

\section{Especificações Técnicas da Instância}
Abaixo estão os dados principais de conexão e as configurações do servidor provisionado:

Sistema Gerenciador (SGBD): MySQL

Host: banco-mysql-08-projetomobilecoding-87ae.c.aivencloud.com

Porta: 18252

Nome do Banco de Dados: defaultdb

Usuário Administrador: avnadmin

Modo SSL: REQUIRED

\section{Segurança e Autenticação}


Visando as melhores práticas de segurança da informação, a senha de acesso ao banco de dados não é exposta no código-fonte. Toda a comunicação da aplicação web com o servidor do Aiven é feita através de uma Connection URI (URI de Serviço), injetada no sistema via variáveis de ambiente.

Além disso, a plataforma exige o uso de SSL/TLS (ssl-mode=REQUIRED), garantindo que todo o tráfego de dados entre a nossa aplicação e o banco de dados seja rigorosamente criptografado.

A string de conexão segue este formato padrão no arquivo de configuração do projeto:

mysql://[USUARIO]:[SENHA]@banco-mysql-08-projetomobilecoding-87ae.c.aivencloud.com:18252/defaultdb?ssl-mode=REQUIRED

Nota: A variável [SENHA] é substituída dinamicamente no ambiente de produção pelo certificado real do Aiven, mantendo a integridade e segurança do acesso.
